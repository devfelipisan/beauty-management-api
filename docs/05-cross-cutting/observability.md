# Observability

Cada operação carrega `requestId`, `correlationId`, `traceId`, `worker`, `serviceVersion`, `tenantId` quando aplicável, actor opaco, operation, status e duration. Nunca registrar JWT, senha, e-mail/telefone completos, CPF, notas técnicas, fotos, documentos, signed URLs ou secrets. Observabilidade não é auditoria.
