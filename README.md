# Beauty Management Monorepo

Backend multiempresa para agenda, confirmação, sinal, clientes, histórico técnico, sessões, pagamentos e retornos.

## Comandos

```bash
npm install
npm test
npm run lint
npm run build
npx wrangler deploy --dry-run
```
